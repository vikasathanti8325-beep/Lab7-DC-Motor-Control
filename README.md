# Lab 7: DC Motor Control

## Project Overview
This project models a DC motor and compares the performance of P, PD, PI, and PID controllers using Python and a Jupyter Notebook.

## State Variables
- Armature current (\(i_a\))
- Angular speed (\(\omega\))
- Rotor position (\(\theta\))

## Features
- DC motor mathematical modelling
- Interactive GUI for motor parameters and controller tuning
- Comparison of P, PD, PI, and PID controllers
- Simulation and plotting of motor responses

## Tools Used
- Python
- Jupyter Notebook
- NumPy
- SciPy
- Matplotlib
- Tkinter (if used in the submitted GUI)

## How to Run
1. Download `Lab7_DC_Motor_Control.ipynb`.
2. Open it using Jupyter Notebook or Google Colab.
3. Run the cells in order and follow the notebook instructions.
